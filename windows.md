# Windows

## What information to gather?
* Basic user/domain information: `whoami` > server01\user123
* User principal name (for domain user): `whoami /upn` > 
* User in FQDN format (for domain user): `whoami /fqdn`
* Logon ID of current user: `whoami /logonid` > S-1-5-5-0-19779146
* Security identifier: `whoami /user` > S-1-5-21-3000311873-2721812345-2103131302-1001
